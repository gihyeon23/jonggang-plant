3링크 복사

지금은 내 컴퓨터의 파일로 열려 있어서, 이 링크는 노션에서 열리지 않아요. GitHub Pages에 배포한 뒤 그 주소에서 링크를 복사하세요.

노션에 붙이는 방법

  1. 노션 페이지에서 /embed 입력 → 임베드 선택
  2. 복사한 링크 붙여넣기 → 링크 임베드
  3. 박스 모서리를 끌어 크기 조절
    • 가로로 길게 (약 400×180) → 식물 + D-day + 진행 바
    • 정사각형 (약 220×220) → 큰 식물 + D-day
    • 얇게 (높이 60 이하) → 한 줄 요약

📱 폰에서 링크를 열면 전체 화면으로 보여요. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
🔒 설정은 모두 링크 안에만 들어 있어요. 쿠키나 브라우저 저장소를 쓰지 않아요.
