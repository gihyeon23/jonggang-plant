# 🌱 종강 D-day 식물 위젯

노션 페이지에 `/embed`로 붙여 쓰는 종강 D-day 위젯이에요.
개강일부터 매주 식물이 한 단계씩 자라고, 종강일에 꽃이 활짝 펴요.

- 순수 HTML / CSS / JavaScript (빌드 도구 없음)
- 설정은 **URL 파라미터로만** 저장해요. 노션 임베드 안에서 막힐 수 있는 쿠키·localStorage는 쓰지 않아요.
- 날짜는 **한국 시간(KST)** 기준으로 계산해요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 위젯 + 링크 생성 페이지 (파라미터가 있으면 위젯, 없으면 생성 페이지) |
| `style.css` | 테마·레이아웃·애니메이션 |
| `app.js` | 날짜 계산, 크기 자동 전환, 링크 생성 |
| `plants.js` | 성장 단계별 식물 SVG |

---

## 1. GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소에 올려요.
   ```bash
   git push -u origin main
   ```
2. GitHub 저장소 페이지 → **Settings** → 왼쪽 메뉴 **Pages**
3. **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더 **/ (root)** → **Save**
4. 1~2분 기다리면 페이지 위쪽에 주소가 나타나요.
   예: `https://<내-아이디>.github.io/jonggang-plant/`

> 저장소가 **Public**이어야 무료 계정에서 Pages를 쓸 수 있어요.
> 코드를 수정해서 다시 push하면 1~2분 뒤 자동으로 반영돼요.

## 2. 노션에 붙이기

1. 배포된 주소(`https://<내-아이디>.github.io/jonggang-plant/`)를 브라우저로 열어요.
2. 개강일·종강일·테마·크기를 고르고 **노션에 붙일 링크 복사**를 눌러요.
3. 노션 페이지에서 `/embed` 입력 → **임베드** 선택
4. 복사한 링크를 붙여넣고 **링크 임베드**
5. 박스 모서리를 끌어서 크기를 조절해요.

| 박스 크기 | 보이는 모양 |
| --- | --- |
| 가로로 길게 (약 400×180) | 식물 + "종강까지 D-86" + 주차 + 16칸 진행 바 |
| 정사각형 (약 220×220) | 큰 식물 + "D-86 · 4주차" |
| 얇게 (높이 60 이하) | "🌱 종강 D-86 · 4주차" 한 줄 |

`size=auto`(기본)이면 박스 크기에 맞춰 자동으로 바뀌어요.

> ⚠️ 내 컴퓨터에서 `index.html`을 직접 열어 복사한 링크(`file:///...`)는 노션에서 열리지 않아요.
> 꼭 GitHub Pages 주소에서 링크를 복사하세요.

### 📱 폰 전체 화면

같은 링크를 폰에서 열면 세로 전체 화면(큰 D-day, 말풍선, 진행 바, 오늘의 한마디)으로 보여요.
Safari/Chrome의 **홈 화면에 추가**를 하면 앱처럼 쓸 수 있어요.

## 3. URL 파라미터

```
https://<내-아이디>.github.io/jonggang-plant/?start=2026-09-01&end=2026-12-21&theme=light&size=auto
```

| 파라미터 | 값 | 기본값 |
| --- | --- | --- |
| `start` | 개강일 `YYYY-MM-DD` | `2026-09-01` |
| `end` | 종강일 `YYYY-MM-DD` | `2026-12-21` |
| `theme` | `light` / `dark` / `transparent` | `light` |
| `size` | `auto` / `wide` / `square` / `mini` (`full`: 폰 전체 화면 강제) | `auto` |
| `debugWeek` | `0`~`17` 성장 단계 미리보기 (0 = 개강 전, 17 = 종강) | 없음 |
| `debugRain` | `1`이면 정각 비를 계속 보여줘요 (미리보기용) | 없음 |
| `edit` | 붙이면 현재 설정이 채워진 링크 생성 페이지를 열어요 | 없음 |

- `transparent` 테마는 배경 없이 노션에 녹아들어요. 글자색은 기기의 라이트/다크 설정을 따라가요.
- 날짜가 잘못되었거나 종강일이 개강일보다 앞이면 기본값을 써요.

## 4. 성장 단계

| 주차 | 모습 |
| --- | --- |
| 개강 전 | 씨앗 봉투 · "개강까지 D-n" |
| 1주차 | 흙 속에서 자는 씨앗 |
| 2~4주차 | 새싹 (주마다 조금씩 커짐) |
| 5~7주차 | 잎이 늘어남 |
| 8주차 | 살짝 시든 모습 + `중간고사` 배지 |
| 9~11주차 | 다시 생기, 줄기가 길어짐 |
| 12~14주차 | 꽃봉오리 |
| 15주차 | 긴장한 꽃봉오리 + `기말고사` 배지 |
| 16주차 | 꽃잎이 살짝 벌어짐 |
| 종강일 이후 | 꽃 만개 + 꽃가루 애니메이션 + "종강 축하해요!" |

- 주차 = 개강일부터 지난 주 수 + 1
- 학기가 16주가 아니어도 16단계에 비례해서 맞춰요.
- 매 정각마다 1분 동안 식물 위로 비가 내려요 (물 주기 💧). 링크 생성 페이지의 **💧 정각 비** 버튼으로 미리 볼 수 있어요.
- 기기에서 "동작 줄이기(prefers-reduced-motion)"를 켜면 애니메이션이 꺼져요.

## 5. 로컬에서 확인하기

`index.html`을 브라우저로 바로 열어도 돼요. 링크 생성 페이지의 **성장 단계** 선택으로 모든 단계를,
**노션 라이트/다크** 버튼으로 배경을 바꿔 볼 수 있어요.

위젯 하나만 보고 싶다면:

```
index.html?debugWeek=8&theme=dark&size=wide
```

> 일부 브라우저는 `file://`에서 iframe 미리보기를 막을 수 있어요. 그럴 땐 간단한 로컬 서버로 여세요.
> ```bash
> python3 -m http.server 8000
> ```
> → http://localhost:8000
